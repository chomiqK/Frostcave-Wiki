# Współtworzenie FrostCave Wiki

Dziękujemy za zainteresowanie rozwojem dokumentacji FrostCave.

Możesz pomóc poprzez:
- poprawianie błędów i literówek,
- aktualizowanie nieaktualnych informacji,
- ulepszanie opisów mechanik,
- zgłaszanie brakujących informacji.

## Pull Request

Przed wysłaniem zmian upewnij się, że:

- informacje są zgodne z aktualnym stanem serwera,
- tekst jest napisany w języku polskim,
- zachowany został obecny styl dokumentacji,
- zmiana nie zawiera niezweryfikowanych informacji.

Większe zmiany mogą wymagać wcześniejszego omówienia w Issue.
